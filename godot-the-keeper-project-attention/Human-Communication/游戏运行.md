

# 游戏启动初始化
Autoload
- Constants.gd
	- 游戏常量
- SignalBus.gd
	- 信号总线（游戏阶段切换信号、资源变化信号...）
- DataManager.gd
	- 负责加载和管理游戏数据（SL）
- Logger.gd
	- 工具类 - 提供分级日志功能，支持文件输出和控制台输出
- SceneManager.gd
	- 场景切换管理（信号总控）
- GameManagers.gd
	- 游戏管理器引用系统
		- 用于存储和访问从load_game场景加载的管理器实例
		- 这些管理器不再是Autoload，而是通过load_game场景初始化后注册到这里


# 新游戏流程
MainScene.tscn
游戏主菜单
- 点击开始新游戏按键

load_game.tscn
游戏加载页面
- ResourceManager.gd
	- 单例，负责管理表构造力、里构造力等资源的生成、消耗、追踪和管理
- ConstructManager.gd
	- 单例，负责管理所有构造体实例的注册、查询、更新和清理
- InvestigatorManager.gd
	- 单例，负责管理所有调查员实例的注册、查询、更新和清理
- CardLibrary.gd
	- 单例，负责管理所有卡牌数据、加载、查询、解锁状态等
- CardUsage.gd
	- 单例，负责卡牌使用验证、逻辑执行、反馈等

所有单例加载完毕则自动跳转游戏主页面

game_scene.tscn
游戏主页面
- GameScene.gd
	- 实例化表里世界至指定Viewport
- 实例化ResourceDisplay.tscn
- 实例化SubViewport中的世界网格
- 实例化HandDisplay.tscn

实例化GridSystem.tscn
