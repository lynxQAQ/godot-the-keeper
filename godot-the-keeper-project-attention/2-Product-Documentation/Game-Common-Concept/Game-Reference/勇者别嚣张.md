
# 勇者别嚣张
日文：勇者のくせになまいきだ
英文：What Did I Do to Deserve This, My Lord!?

## 总述  
《勇者别嚣张》是一款以“反英雄”为主题的策略模拟游戏，玩家扮演魔王方，通过经营地下迷宫对抗前来讨伐的勇者，强调系统博弈而非直接操作战斗。

## 核心玩法
- **迷宫经营**：挖掘地形、布置生态，构建可持续运作的地下系统。
- **怪物生态链**：通过食物链关系培育怪物，形成自动成长与相互制衡。
- **资源与节奏管理**：在有限行动与时间压力下做出最优决策。
- **间接对抗**：不直接控制战斗，而通过系统设计“让勇者失败”。
