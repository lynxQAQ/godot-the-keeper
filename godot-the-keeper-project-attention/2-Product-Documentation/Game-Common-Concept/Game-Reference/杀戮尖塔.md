
## 总述 
《杀戮尖塔》是一款融合卡牌构筑与肉鸽要素的单人策略游戏，玩家通过不断攀登高塔，在随机事件与战斗中完成角色构筑并推进进程。

## 核心玩法
- **卡牌构筑**：在战斗与事件中获取、强化或移除卡牌，形成高效牌组。
- **回合制战斗**：基于能量与抽牌机制，进行高信息量的策略决策。
- **随机路径与事件**：地图路线、敌人和奖励具有不确定性，强调风险管理。
- **单局循环与成长**：单次失败即结束，但解锁内容推动长期体验深化。
