真理之茧（Truth Cocoon）是[[里世界]]的原貌，网格视图的每个单元格都是一个真理之茧；[[守密人]]可以通过[[破茧]]行为使其转换为[[真理要素]]。

真理之茧可以类比为[[勇者别嚣张]]中的土块；茧的形态会随着受影响的程度发生变化，受影响程度越深的茧将有更大概率破出更具有影响力的[[真理要素]]或[[实体]]/[[虚体]]。

真理之茧具有等级，其等级由[[寂灭]]次数决定：
即初始的真理之茧等级为0，当其被[[破茧]]转化为的[[真理要素]]完成了[[寂灭]]并形成新的[[真理之茧]]后，其会转换为等级为1的真理之茧；循环往复，真理之茧的等级等于[[寂灭]]次数。

真理之茧的属性遵循[[地图单位-里世界]]。
