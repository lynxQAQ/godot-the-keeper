里世界（Inner World）是相对[[表世界]]存在的、隐藏在常规认知之外的空间，常出现在奇幻、悬疑、恐怖类作品中，它可能是意识的映射、平行维度，或是被规则扭曲的特殊领域，往往与表世界存在关联但遵循截然不同的运行法则。

游戏中的里世界是培育[[实体]]和[[虚体]]的“生态培养皿”（可以参考[[勇者别嚣张]]的生态实现）。

里世界的地图构造在理解上可以拆分为两种地图单位：
- 已开垦的网格单位
- 未开垦的网格单位

玩家（即[[守秘人]]）可以通过消耗[[里构造力]]对里世界地图进行[[开垦]]——使未开垦的网格单位转换为已开垦的网格单位。
[[真理要素]]只能在已开垦的网格单位上移动。
里世界不同于[[表世界]]的[[迷宫]]构成要求，里世界中开垦网格单位不需要遵循“任意两个已开垦的网格单位必须组成通路”的规则。
