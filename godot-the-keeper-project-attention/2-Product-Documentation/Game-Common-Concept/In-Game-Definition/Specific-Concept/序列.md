序列是指构造体的存在形式，可以理解为构造体的等级。

[[实体]]的序列从低到高为：
- Totem - 图腾：[[1-图腾]]
- Creature - 造物：[[2-造物]]
- Malevolence - 邪祟：[[4-邪祟]]
- Abomination - 魔物：[[3-魔物]]
- Divine - 神祇：[[5-神祇]]

[[虚体]]的序列从低到高为：
- Omen - 预兆：[[1-预兆]]
- Aberration - 异象：[[2-异象]]
- Revelation - 启示：[[3-启示]]
- Cataclysm - 灾厄：[[4-灾厄]]
- Oracle - 神谕：[[5-神谕]]

序列越高的构造体通常具有更强力的效果。
