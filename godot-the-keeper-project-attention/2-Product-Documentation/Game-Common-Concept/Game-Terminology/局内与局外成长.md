
**局内成长（Run Growth / In-Run Progression）**
- 定义：在单次游戏运行（单局）中，角色通过战斗、拾取道具或事件获得的即时能力增强。
- 特点：
    - 仅在当前局有效，局外重开后失效。
    - 影响策略决策，如选择升级路线或道具搭配。
- 示例：提升攻击力、获得新的技能、临时增益道具。


**局外成长（Meta Progression / Out-of-Run Progression）**
- 定义：跨局生效的长期进展，通过多次游戏积累角色解锁、永久属性或系统奖励。
- 特点：
    - 保持在多局游戏中，增强长期游戏体验。
    - 常用于解锁新角色、新卡牌或永久属性加成。
- 示例：解锁新职业、增加初始生命值、永久获得金币增益。
