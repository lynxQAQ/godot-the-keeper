
## 常用文档简介与目录
## [[产品总述]]
该文件涵盖了游戏设计的核心理念和核心要素，以及游戏实现效果的预期。

## Game-Common-Concept/
该文件夹涵盖了文档描述中可能涉及的游戏相关概念及游戏中可能出现的单位对象的定义。
- /Game-Reference/
	- 用于存放可供参考的市面上的游戏及其简介。
- /Game-Terminology/
	- 用于存放游戏术语，方便理解抽象概念或总结性的专有名词。
- /Game-Type/
	- 用于存放游戏类型及其相关介绍，方便理解游戏借鉴的玩法及分类。
- /In-Game-Definition/
	- 用于存放本项目独特定义的概念，这些概念是原创词汇，专属于本项目及产品使用——如存在与项目外的词汇雷同与冲突，则仍以此文件夹下的定义为准进行理解。
- /In-Game-Element-Attribute/
	- 用于存放本项目游戏元素的属性，这些属性会由不同的游戏元素对象所会绑定；文件夹中存放的是属性的定义及说明，具体什么元素会携带什么属性由/In-Game-Element-Unit/中对游戏元素单位进行定义。
- /In-Game-Element-Unit/
	- 用于存放本项目的游戏元素及其作为单位对象的属性构成。

## User-Interaction/
该文件夹下涵盖了用户交互过程中可能涉及的界面及行为的具体对照描述。
- /User-Interface-Layout/
	- 用于存放游戏界面中具体的布局分区及其功能描述。
