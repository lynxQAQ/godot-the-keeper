
# 项目概述
本仓库（Obsidian Vault: Game-The-Keeper）用于**游戏项目管理**与**文档沉淀/跟进**，覆盖从立项、需求、设计、实现到版本发布与迭代的全流程记录。

- **游戏类型**：Rogue-like + 卡牌 + 合成 + 塔防
- **引擎/语言**：Unity / C#
- **目标平台**：PC（Steam 为主要发行渠道）

---

# 使用约定
## 命名规范
- **文件夹命名以英文为主**，标题清晰可检索
- **文件命名以中文为主**，标题清晰可检索

## 进度跟踪方式
- 里程碑、阶段拆解放在 `1-Development-Progress/`
- 每次推进在对应阶段下追加：**完成项 / 风险 / 下一步 / 阻塞**
- 需要讨论的问题统一收敛到“待决策/待评审”清单（放在进度文件中或单独建页）

---

# 文件夹用途概述与入口
## .obsidian/
- **Obsidian 配置目录**（主题、插件、工作区等）。

## 0-Skills/（技能与可复用知识库）
用于沉淀可复用的知识与规范，存放文档与代码通用书写规范、
文件夹使用说明：[[0-Skills/README]]

## 1-Development-Progress/（开发进度与里程碑）
用于理解项目进展与执行计划时间线：阶段拆解、任务推进、风险与决策记录。
文件夹使用说明：[[1-Development-Progress/README]]

## 2-Product-Documentation/（产品/设计文档）
用于阐述项目需求与解释实现细节，对完整产品进行全面设计与预期管理。
文件夹使用说明：[[2-Product-Documentation/README]]

## 3-Compendium/（图鉴）
用于陈示产品中所原生的数据实例，例如游戏中的怪物图鉴、卡牌图鉴等。
文件夹使用说明：[[3-Compendium/README]]

## Images-Repo/（图片仓库）
用于统一管理文档所需的图片资源，避免散落各处。
文件夹使用说明：[[Images-Repo/README]]
